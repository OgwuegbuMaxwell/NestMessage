# NestMessage

NestMessage is a lightweight messaging API built with [NestJS](https://nestjs.com/).  
It allows users to store, retrieve, and manage messages via RESTful endpoints.  
Perfect for learning NestJS or using as a starter template for backend projects.

## Features

- Create and store messages
- Retrieve all messages
- Fetch a specific message by ID
- Clean modular architecture using NestJS
- json file storage
